# Principles Before Committing - KidsteamConversationAgent

This document outlines essential steps and principles before submitting changes to the conversational AI project.

## Pre-Commit Checklist



### 1. Documentation Updates
- **Update `LEARNING_KNOWLEDGE.md`** - Log any new technical knowledge, concepts, confusions and its solutions learned during today's work
- **Update `WORK_LOG.md`** - Document all changes made today, including:
  - Files modified or created
  - Features added or bugs fixed
  - Configuration changes
  - Reasons for changes



Remember: **Good documentation today saves hours of debugging tomorrow!**
Remember: This project involves real-time audio processing, cloud services, and child-user interactions. Thorough testing ensures a smooth educational experience.
